## 更新

不要直接改產生出來的 `.html`。版面在 `src/template.html` + `src/style.css`，文字在 `i18n/<語言>.json`（zh / en / ms / ja / ko，五份結構相同）。改完執行：

```bash
python3 build.py
```

會重新產生 `index.html`（中文）、`en.html`、`ms.html`、`ja.html`、`ko.html`。
